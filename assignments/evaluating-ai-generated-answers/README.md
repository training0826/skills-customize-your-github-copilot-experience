# 📘 Assignment: Evaluating AI-Generated Answers

## 🎯 Objective

Learn how to evaluate AI-generated answers instead of accepting them automatically. You will compare AI responses with reliable sources, identify inaccuracies or bias, and improve a prompt to produce a more useful answer.

## 📝 Tasks

### 🛠️ Examine an AI-Generated Answer

#### Description

Ask an AI tool a factual question related to a school subject or everyday topic. Record the question and answer, then identify claims that should be checked before they are trusted.

#### Requirements

Completed work should:

- Include the exact prompt used to ask the question.
- Include the AI-generated answer or a brief transcript of it.
- Identify at least three factual claims made in the response.
- Mark which claims require verification and explain why.

### 🛠️ Verify Claims with Reliable Sources

#### Description

Research the claims you identified using reliable sources, such as a government website, a school or university website, a library resource, or a reputable news organization. Compare the evidence with the AI-generated answer.

#### Requirements

Completed work should:

- Use at least two reliable sources.
- Provide a link or citation for each source.
- Label each claim as accurate, inaccurate, incomplete, or uncertain.
- Explain at least one difference between the AI response and the evidence.
- Identify any missing context, unsupported statement, or possible bias.

### 🛠️ Improve the Prompt and Response

#### Description

Rewrite the original prompt to request a more accurate and useful answer. Ask the AI tool the revised prompt, then review the new response using the same verification process.

#### Requirements

Completed work should:

- Show the revised prompt and explain at least two changes made to it.
- Ask the AI tool to identify uncertainty and provide sources or suggestions for verification.
- Compare the original and revised responses.
- State whether the revised response is more useful and support the conclusion with evidence.
- Write a final reflection describing when AI-generated information should be checked by a person.
